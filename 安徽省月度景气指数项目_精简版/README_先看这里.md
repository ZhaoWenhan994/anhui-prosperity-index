# 安徽省月度景气指数项目（精简版）

这是给复试展示和快速查看用的精简目录。建议按下面顺序打开：

1. `01_报告与表格/安徽省月度景气指数分析报告.pdf`：最适合直接查看和提交的正式报告。
2. `01_报告与表格/安徽省月度景气指数分析报告.docx`：可编辑的 Word 正式报告。
3. `01_报告与表格/安徽省月度景气指数分析结果.xlsx`：核心结果表，包含建模数据、景气指数、预测、滚动验证、主成分载荷和数据说明。
4. `01_报告与表格/安徽省月度景气指数统计报表.xlsx`：国家统计局原始月度指标整理表。
5. `02_核心代码/src/anhui_index/`：数据处理、主成分分析（PCA）指数、季节性 ARIMA 模型（SARIMA）、预测和报告代码。
6. `03_结果数据/`：处理后的月度数据、指数结果、预测结果和验证结果。

## 文件夹说明

- `01_报告与表格`：最重要的成果，优先看这里。
- `02_核心代码`：项目代码的集中副本。
- `03_结果数据`：代码运行后生成的 CSV 数据。

统计报表和核心结果 Excel 的主数据页都采用“行=时间、列=变量 1—5”的宽表布局；原始长表保留在统计报表的隐藏页中。

完整可复现项目位于同级目录的 `安徽省月度景气指数项目`，运行步骤见其中的 `README.md`。

精简版主要用于阅读和展示；需要重新运行项目时，请使用上面的完整项目目录。
