# 安徽省月度生产与投资景气指数：项目设计

## 目标

构建一个可复现的 Python 项目：从国家统计局公开数据读取安徽省月度指标，形成生产与投资景气指数，预测未来三个月，并自动输出图表与解读报告。

项目服务于应用统计复试展示，也训练数据清洗、主成分分析、时间序列预测和滚动验证能力。

## 研究边界

- 地区固定为安徽省。
- 频率固定为月度；样本期从各指标可共同取得的最早月份开始，截止下载时的最新完整月份。
- 指数反映生产、投资和工业经营，不宣称代表全部宏观经济或居民福祉。
- 社会消费品零售总额作为单独的季度观察图，不并入月度 PCA 指数。
- CPI 作为价格稳定性辅助指标，不并入 PCA 指数，因为其经济含义不是单调的“越高越好”。

## 核心指标

| 字段名 | 官方指标 | 频率与口径 | 方向 | 用途 |
| --- | --- | --- | --- | --- |
| `industrial_yoy` | 工业增加值同比增长 | 当月同比（%） | 正向 | 生产景气 |
| `investment_cum_yoy` | 固定资产投资完成额累计增长 | 累计同比（%） | 正向 | 投资扩张 |
| `profit_cum_yoy` | 利润总额累计增长 | 累计同比（%） | 正向 | 企业经营 |
| `power_yoy` | 发电量同比增长 | 当月同比（%） | 正向 | 实体活动代理 |
| `ppi_yoy` | 工业生产者出厂价格指数 | 上年同月=100，转换为 `value - 100` | 正向 | 工业需求和价格环境 |
| `cpi_yoy` | 居民消费价格指数 | 上年同月=100 | 不入模 | 报告辅助 |

所有数据来源于国家统计局“国家数据”平台的分省月度数据，地区筛选为安徽省。每次下载均记录下载日期、指标原名、数据口径和来源链接。

## 数据与目录

```text
data/
  raw/                         # 原始下载文件，不修改
  processed/anhui_monthly_indicators.csv
  metadata/data_dictionary.xlsx
src/
  download.py                  # 数据获取或导入
  preprocess.py                # 清洗、口径转换与质检
  index.py                     # PCA 指数构建
  forecast.py                  # 预测与滚动验证
  report.py                    # 图表与文字报告
outputs/
  figures/
  report.html
```

`data_dictionary.xlsx` 是面向阅读和答辩的指标字典；建模时 Python 始终读取 CSV 和原始文件，而不是让人手工维护建模表。

## 数据处理规则

1. 日期统一为每月第一天，按升序排列并检查重复。
2. PPI 由指数转换为同比偏离值（指数减 100）。
3. 累计同比指标保留官方口径，不从累计值逆推当月值；报告明确说明这个限制。
4. 缺失值不做跨月插值。若 PCA 核心样本存在缺失，仅在可解释且连续性合理时使用前向填充，否则缩短共同样本期。
5. 在 PCA 前按训练样本进行 Z 标准化，避免量纲主导结果和测试集信息泄漏。
6. 对极端值生成标记并在报告展示；不静默删除官方观测值。

## 建模与评估

1. 用 PCA 提取第一主成分；若其经济方向为负，统一乘以 -1。
2. 将指数线性缩放为基期 100；优先使用共同样本的首个完整年度均值。若没有完整年度，则使用首个至少有 10 个有效月份的年份，并在报告中写明基期并非完整年度及实际观测数。
3. 用 AIC/BIC 在候选 SARIMA 模型中选择景气指数预测模型，同时以季节性朴素预测作基线。
4. 采用滚动起点验证，评估 1、2、3 月预测的 MAE 与 RMSE。
5. 只有当模型优于或至少不明显劣于基线时，才在报告中将其作为推荐预测；否则如实保留基线结果并说明原因。

## 输出与验收

- `data_dictionary.xlsx`：指标、口径、频率、方向和官方来源。
- 清洗数据：一行一个月份，列名稳定，包含质量标记。
- 图表：指标走势、PCA 载荷、景气指数与预测区间、CPI 与季度社零观察。
- HTML 报告：最新读数、预测、验证误差、数据局限与可复现运行命令。

验收标准是：从空的 `data/raw/` 开始执行文档指定命令，可生成相同结构的数据集、图表和报告；每张图和每一个数值可追溯至官方指标名和处理规则。

## 风险与应对

- 国家统计局页面的下载接口可能调整：下载模块与清洗模块分离，允许将手工下载的原始 Excel 放入 `data/raw/` 后继续自动处理。
- 指标起始时间可能不同：以共同样本期建模，并在报告显示每列覆盖范围。
- 样本量有限：控制变量数量为 5 个，预测模型保持简单，以滚动验证而非样本内拟合判断效果。
